# Auto Cost & Savings USA

A practical, US-focused car ownership cost toolkit. Built with plain HTML, CSS, and JavaScript for fast static hosting.

## Local preview
Open `index.html` in a browser.

## Tools
- Auto loan payment calculator
- Gas vs. electric cost calculator
- Fuel cost calculator
- EV savings calculator
- Car maintenance budget planner

All estimates are educational and depend on the assumptions entered by the visitor.
